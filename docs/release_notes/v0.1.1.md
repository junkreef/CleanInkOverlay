## v0.1.1 で変わったこと

使い方と記録の内容は v0.1.0 と同じです。zip に同梱しているソフトウェアのライセンスの条件を満たすための修正です。

zip には、OpenCV（画像の読み取りに使っているライブラリ）に付いてくる **FFmpeg**（動画ファイルを読むための部品）が入っています。
FFmpeg は LGPL というライセンスで、配るときには「何が入っているか・どのライセンスか・ソースコードはどこにあるか」を
示す必要があります。v0.1.0 にはその案内がありませんでした。

- **FFmpeg についての案内を追加**：zip の `THIRD_PARTY_NOTICES.txt` に、次のことを書きました。
  - 中身は OpenCV プロジェクトがビルドした FFmpeg n7.1（libvpx v1.16.0・aom v3.14.1 を含む）で、GPL や non-free の部品は入っていないこと
  - ライセンスは LGPL 2.1 以降で、本文は `runtime\python\Lib\site-packages\cv2\LICENSE-3RD-PARTY.txt` にあること
  - 入っているファイル（`opencv_videoio_ffmpeg500_64.dll`）は手を加えていないもので、自分でビルドしたものに差し替えてよいこと
  - ビルド元（[opencv/opencv_3rdparty](https://github.com/opencv/opencv_3rdparty/tree/06dc20cad65dc7fcf784f70c95d46750520889a7/ffmpeg) のコミット `06dc20ca`）と、
    そこにあるソースコードの取得スクリプト・ビルドスクリプト
- **Web 画面に入っている React などのライセンス本文を同梱**（`web\licenses`）。v0.1.0 では名前だけで、本文が入っていませんでした。
- **録画ファイルの解析は必ず FFmpeg で開く**ようにしました。FFmpeg が使えないときに別のデコーダーで開いてしまい、
  読み間違えた記録が残るのを防ぐためです（ライブでの記録には関係ありません）。

v0.1.0 の zip をお使いの場合は、v0.1.1 に入れ替えてください（新しい zip を展開して起動するだけで、記録は引き継がれます）。
