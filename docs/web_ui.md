# Web UI と配信オーバーレイ

`web/` (React + Vite)。バックエンド (`app/backend.py`) が `web/dist` を `/` で、オーバーレイ (`web/overlay.html`、ビルド不要の単体 HTML) を `/overlay` で配る。更新は WebSocket `/ws` で届く (`match_saved` / `match_deleted` / `signatures_changed` / `weapon_icons_changed` / `recorder` / `session`)。

## ヘッダー

- **記録の開始 / 停止** (● 記録開始 / ■ 記録停止)。状態をクリックするとデバイスの選択とレコーダーのログ。
- **配信セッションの開始時刻** のチップ (「セッション 09:00〜」)。クリックで `SessionPicker.jsx` が開く。
  - テキスト欄・カレンダー・時計・直近 4 試合・「今から」が 1 つの値を共有して連動する。どれも値を変えるだけで、確定は「変更」か Enter (Esc で閉じる)。変更のトーストに「元に戻す」が付く。
  - 日付をまたぐときは、カレンダーで前の日を選ぶか「昨日 23:10」「10/30 23:10」と入力する。未来の日はカレンダーで選べず、今日の未来の時刻はヒントが赤くなり確定できない。
  - キーボードとマウス前提で、ドラッグの処理はない。時計は 24 時間表示 (外周 12〜23、内周 0〜11) で、時をクリックすると分 (5 分刻み) に移る。1 分単位は ↑↓ か入力欄。
  - 開始時刻はバックエンドのメモリ上だけに持つ (永続化しない: 翌日の起動で前日の値が残らないように)。起動時刻が初期値。WebSocket の再接続時に `/api/overlay` で読み直し、値が変わっていれば再起動の通知 + 「元に戻す」。
  - API: `POST /api/overlay/session {start?}` (ISO 時刻、省略で今)。不正な形式と未来の時刻は 400。

### ガチの試合の表示

- ナワバリで塗り % を出していた所に、ガチではカウントを出す (チームのポイントは最終値がカウント × 5 なので出さない)。ガチ = カウントが読めた試合か、ルール名が「ガチ…」の試合 (ルール画面に名前の無いガチもカウントで拾う)。
- 試合一覧の「スコア」列 (`Score.jsx`): ナワバリ「66.4 - 28.9」、ガチ「89 - 88」、ノックアウトは KO 印。ルールは色付きのタグ。
- 試合詳細: 見出しに「100 - 0 カウント」と「ノックアウト勝ち / 負け」。「カウントの推移」のグラフ (`MatchDetail.jsx` の `GachiChart`): 0 が真ん中、味方のカウントが上、相手が下。線の下の帯 = カウントが動き出すまでに取り返す分 (エリア / アサリ: ペナルティ、下端の点線 = カウント − ペナルティ。ヤグラ / ホコ: 最高到達点から今の位置まで、白い線 = 位置)。延長戦は網かけ、マウスを乗せるとその秒の値。HUD の見えない秒はつなぐ (カウントは前の値、ペナルティは 3 秒まで前の値でそれ以上は 0、位置は 3 点の中央値と 12 秒までの直線補間)。ルール名の分からない試合はデータのある方で描く。
- 統計: 「ルール」の絞り込み (すべて / ガチ全部 / ルール名)。カウントのある試合が入っているときだけ KPI に「KO 勝ち / 負け」と「平均カウント差」。「ルール別」カード。

## 配信オーバーレイ (`/overlay`)

OBS の「ブラウザ」ソース (1920x1080) で、ゲームキャプチャ (左上 1600x900) の**上**に重ねるページ。ゲームの領域は透明に抜いてあり、見出しや演出がゲーム側へはみ出せる。OBS の中か `?obs=1` ではゲーム領域の目安表示を消す。

- **レイアウト**: 右の縦列 (x 1600〜1920) = セッションの戦績 (試合数と勝敗、連勝 / 連敗、たおした / やられた / スペシャル、最多たおした、最高塗りポイント、やられたブキ TOP3 など。細かい項目は `web/overlay.html` を見る)。下の帯 (y 900〜1080) = 最新のバトル (ステージ / ルール / 開始時刻 / 塗り % かカウントのバー / 成績 / 表彰) と直近の試合のカード (既定 6 枚、`?limit=`)。
- **データ**: `GET /api/overlay?since=&limit=` → `{session, recent, last, all_time, recorder, session_start}`。`since` は ISO 時刻 / `today` / `all`、省略時は配信セッションの開始 (上の SessionPicker)。集計は `Store.overlay`。
- **更新**: `match_saved` で読み直して演出 (WIN! / LOSE... のバナー、数字のカウントアップ、新しいカードのスライドインなど)、`session` / `match_deleted` で読み直し、`recorder` で状態のピル (ロビー / バトル準備中 / バトル中! / リザルト待ち / 記録オフ)。15 秒ごとのポーリングも併用。
- **ガチ**: 最新のバトルのバーはカウントの割合で埋める。ノックアウトは「KNOCKOUT!」をバーの上に斜めに乗せる。直近のカードはガチなら「89 / 88」、ノックアウトは頭に「KO!」。8 枚 (`?limit=8`) にするとカードが細くなり「KO! 100 / 0」が折り返す (標準の 6 枚なら崩れない)。セッションの戦績はナワバリとガチを合算する。
- **フォント**: Google Fonts の Mochiy Pop One、数字は Adobe Fonts の CC That's All Folks (`config.toml` の `overlay.adobe_fonts_kit` の Web プロジェクトから読む)。未設定なら Rubik Black。Bangers は 1 と 7 が見分けにくいので使わない。届かなければ丸ゴシック系にフォールバック。
- `?demo=1` で 5 秒ごとに架空の試合を足して演出を確かめられる (DB には書かない。1 試合おきにガチヤグラ)。
- ヘッドレスのブラウザのスクリーンショットでは requestAnimationFrame が回らずカウントアップが止まって見えるが、実ブラウザでは動く (setTimeout で最終値に着地する保険がある)。
