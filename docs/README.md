# CleanInkOverlay ドキュメント

Splatoon 3 (日本語 UI) のキャプチャ映像 (1920x1080 / 60 fps) を解析して、試合ごとの勝敗・8 人の成績・キル / デス・スペシャル・ガチルールのカウントと時系列を SQLite に記録し、Web UI と配信オーバーレイで見せる。

文字は OCR で読まない。Windows 標準 OCR (`winocr`、日本語) は Splatoon の丸いフォントに弱く (「ひらパー」→「むらバ-」、バナーは「し ギ ュ ラ 々 ッ チ」)、使い物にならなかった。代わりに、画面のフォントと位置が固定であることを使い、数字は字形テンプレート (グリフ集) で、ステージ名・表彰名などの文字列は白文字の画像をそのまま「署名」にして同じかどうかだけを判定する。名前は人があとから一度だけ付ける。

## 読む順番

1. **architecture.md** で全体の部品と動かし方をつかむ。
2. **match_flow.md** で、ゲームがどの順に画面を出すかを見る。ほかのページはこの流れのどこかを読む話。
3. **recorder.md** と [recorder_states.svg](recorder_states.svg) で、その画面の流れをレコーダーがどう追うかを見る。
4. 個別の読み取りは興味のある順に: **hud.md** (試合中)、**result_screens.md** (試合後)、**weapon_icons.md**、**signatures.md**、**ranked_rules.md** (ナワバリ以外)。
5. 記録の形は **data_storage.md**、見せ方は **web_ui.md**。
6. 手を入れる前に **limitations.md** を見る。

## 決まりごと

- **座標** は 1080p のフレームの画素。文中では「y 48〜104、x 905〜1015」と書く。コードの矩形は `(y0, y1, x0, x1)` の順のタプルが多い (`hud.TIMER = (48, 104, 905, 1015)`)。
- **左 = 自チーム**。ルール画面のカード、HUD のイカ枠、ジャッジくん画面と リザルト表の % / カウントは、勝ち負けによらず左 (または前の 4 つ) が自分のチーム。リザルト表の行だけは WIN! の 4 行が上、LOSE... の 4 行が下で、自分が負けると自分のチームは下になる。
- **スロット** 0〜7 は HUD のイカ枠の並び (0〜3 味方、4〜7 敵) で、ルール画面のカードの並びと同じ。DB の `match_players.slot` もこれ。
- **時刻** は、動画の秒 (「動画内 52.3 秒」) と、試合の秒 (タイマーが動き出した時刻 t0 からの経過、DB の `t_ms` / `t_s`) を区別する。
- **位相**: 入力は 60 fps で、解析するのは 6 コマに 1 コマ (約 10 fps)。6 コマのどこから数え始めたかを「位相」と呼ぶ ([recorder.md](recorder.md#サンプリングと位相))。
- **サンプル録画** は `YYYY-MM-DD_HH-MM-SS.mp4` (OBS の録画名) で呼ぶ。録画・保存画面・DB は配布しない (ほかのプレイヤーの名前が写っている)。数値はこれらの録画やライブの保存画面で測ったもの。
- 例に出てくる「ひらパー」はこのツールの作者のプレイヤー名。

## 用語

| 用語 | 意味 |
|---|---|
| ルール画面 | 試合開始前の「ルール / ○○バトル」と 8 枚のプレイヤーカードの画面 |
| HUD | 試合中の上部のタイマーとイカ枠、右上のゲージなど |
| イカ枠 | HUD 上部の 8 人分のイカ / タコのアイコン (スロット) |
| キルフィード | 画面下中央の「○○ をたおした!」の帯 (キルログ) |
| やられた吹き出し | 自分がやられたあと中央に出る黒い吹き出し「(ブキ) で やられた!」と相手のカード (バブル) |
| ジャッジくん画面 | Finish! のあと、塗り % (ガチはカウント) と WIN! / LOSE... が出る画面 |
| 個人パネル | 自分のキャラ・バナー・自分の行・「ゲットした表彰」・ギアの画面。レコーダーは「表彰 (medals)」として検出する |
| リザルト表 | 8 人の成績の表 (スコアボード) |
| 署名 | 白文字などの画像を固定サイズのベクトルにしたもの。同じ文字列なら相関が高い ([signatures.md](signatures.md)) |
| グリフ集 | 数字の字形テンプレート (`assets/glyphs/*.json`) |
